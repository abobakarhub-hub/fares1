# علماء العرب — منظومة العصر العباسي الذهبي

موقع تفاعلي أسطوري يخلّد تسعة من أعلام علماء العصر العباسي في ثلاثة مجالات: **الفلك**، و**الرياضيات**، و**الفيزياء** — بأسلوب المخطوطات المذهّبة: خلفية ليلية كونية، زخارف نجمية ثمانية، بطاقات ثلاثية الأبعاد تميل وتنقلب بين يديك، خط أميري للعناوين، وواجهة عربية كاملة من اليمين إلى اليسار.

## أقسام الموقع

| القسم | المحتوى |
| --- | --- |
| الإهداء وصانع الموقع | إهداء بروح كتب التراث مع ختم محرابي دوّار ورسالة شكر |
| بيت الحكمة | مدخل تاريخي إلى العصر الذهبي العباسي |
| الفصول الأربعة | لوائح تراثية: نهضة الترجمة، عصر الرصد، ثورة الرياضيات، ميلاد المنهج التجريبي |
| الفلك | البتاني، عبد الرحمن الصوفي، ابن الشاطر |
| الرياضيات | الخوارزمي، ثابت بن قرة، عمر الخيام |
| الفيزياء | الحسن بن الهيثم، البيروني، الخزيني |
| خط الزمن | محطات عباسية مفصلية من بغداد إلى القمر |
| على القمر | فوهات قمرية تحمل أسماء هؤلاء العلماء |
| عالم الكلمات | مصطلحات عربية شكّلت لغة العلم |
| حقائق مذهلة | لمسات سريعة تُبهر الزائر |
| خلاصة الإرث | أثرهم الممتد إلى علوم اليوم |

## التقنيات المستخدمة

- **Next.js 16** (App Router) + **TypeScript**
- **Tailwind CSS 4** مع نظام لوني ليلي ذهبي مخصص
- **Three.js** لمشهد كوني ثلاثي الأبعاد حيّ في الواجهة
- **Framer Motion** لحركات الظهور والانقلاب ثلاثي الأبعاد
- خطا **Amiri** للعناوين التراثية و**Cairo** للنصوص
- أرقام عربية مشرقية (٢ع٣) وتخطيط RTL كامل

## التشغيل محليًا

```bash
# تثبيت الحزم
bun install   # أو: npm install

# تشغيل خادم التطوير
bun run dev   # أو: npm run dev
```

ثم افتح المتصفح على `http://localhost:3000`.

## بناء نسخة الإنتاج

```bash
bun run build   # أو: npm run build
bun run start   # أو: npm run start
```

## النشر المباشر للزوار (اختياري)

- **Vercel** هي الأنسب لمشاريع Next.js: استورد المستودع من لوحة Vercel واضغط Deploy، وسيمنحك رابطًا مباشرًا يشاركه الزوار.
- ملاحظة: GitHub Pages يعرض ملفات ثابتة فقط ولا يشغّل خوادم Next.js، فاستخدمه فقط بعد تحويل المشروع إلى تصدير ساكن.

## بنية المشروع

```
src/
  app/            # التخطيط العام والصفحة الرئيسية والأنماط
  components/     # أقسام الموقع: Hero, Creator, HouseOfWisdom, FieldSection, Timeline, MoonNames, WordsWorld, AmazingFacts, Legacy...
    ui/           # مكونات واجهة جاهزة (shadcn/ui)
  lib/scholars.ts # بيانات العلماء التسعة وخط الزمن
public/scholars/  # صور رمزية للعلماء
```
